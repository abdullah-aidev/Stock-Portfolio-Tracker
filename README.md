# 📈 CodeAlpha Stock Portfolio Tracker

## 📌 About the Project

The Stock Portfolio Tracker is a beginner-friendly Python project developed as part of the CodeAlpha Python Internship. It allows users to track their stock investments by entering stock symbols and quantities.

## ✨ Features

* Displays available stocks and their sample prices.
* Allows users to add multiple stocks to their portfolio.
* Calculates the value of each stock holding.
* Calculates the total portfolio investment.
* Validates stock symbols and quantities.
* Generates a portfolio report in a text file.
* Uses Python dictionaries, loops, conditional statements, and exception handling.
